This folder holds downloadable spreadsheet templates that the
/toolkit page links to.

Add files here (.xlsx is the standard) and reference them from
toolkit.html with:

  <a href="assets/toolkit/your-template.xlsx" download>Download</a>

Recommended naming: kebab-case, no spaces.
  dcf-template.xlsx
  comps-template.xlsx
  lbo-template.xlsx
  earnings-tracker.xlsx
